BACKGROUND IMAGE SETUP
======================

REQUIRED FILE:
--------------
Place the vibrant cityscape image here as:
city-background.jpg

The image should be the bright blue/cyan cityscape with buildings.

CURRENT STATUS:
---------------
The CSS is configured to use this image as the background for:
1. The main game screen (with dark overlay for readability)
2. The title screen
3. The body background

If the image is not present, the game will fall back to the purple gradient.

INSTRUCTIONS:
-------------
1. Save your cityscape image as "city-background.jpg"
2. Place it in THIS folder (/home/user/MCP/rhythm-game/assets/images/)
3. Refresh the game in your browser

IMAGE REQUIREMENTS:
-------------------
- Format: JPG or PNG
- Recommended size: 1170 x 2532 pixels (iPhone dimensions)
- Or any portrait-oriented image
- Vibrant colors work best!
